起動丸エージェント.

起動丸で、スマホからこの PC をスリープ・画面ロック・再起動・シャットダウンできるようにする常駐アプリです。ゲームの起動など、自分で作った操作も足せます。

Windows・Mac・Linux に対応しています(Linux は Ubuntu で動作確認)。管理者の権限は要りません。

インストール

  1. スタートボタンを右クリックして「ターミナル」(または「Windows PowerShell」)を開きます
  2. 下の 1 行を貼り付けて Enter を押します
irm https://pc.kido.page/install.ps1 | iex
  1. 「ターミナル」を開きます(Spotlight で「ターミナル」と入力)
  2. 下の 1 行を貼り付けて Enter を押します
  3. 再起動・シャットダウン用の許可を入れるか聞かれたら、Enter を押して Mac のログインパスワードを入れます(入力中の文字は表示されません)
curl -fsSL https://pc.kido.page/install.sh | sh
  1. 端末を開きます(Ubuntu なら Ctrl + Alt + T)
  2. 下の 1 行を貼り付けて Enter を押します
curl -fsSL https://pc.kido.page/install.sh | sh

このあと

  1. ファイアウォールの許可 — Windows では「Windows セキュリティ」の確認が出ます。「許可」を押してください(起動丸の本体から、この PC に届くようにするためです)。Mac でも「受け入れる接続を許可しますか」と聞かれたら「許可」を押します。
  2. 本体と組む — 画面に「起動丸の本体が見つけに来るのを待っています」と出て、10 分のあいだ待ちます。起動ページにこの PC をまだ登録していなければ、そのあいだにスマホで登録してください。「✓ 本体とつながりました」と出れば終わりです。
  3. 操作フォルダが開く — スマホに、スリープ・画面ロック・再起動・シャットダウンの 4 つが並びます。

自分の操作を足す

ホームフォルダの KidoButtons(Windows なら C:\Users\あなたの名前\KidoButtons)が操作フォルダです。スタートメニューの「起動丸の操作フォルダ」からも開けます。

  1. Kido の中にフォルダを作ります。フォルダ名がそのままスマホに出る名前になります(先頭の 50_ のような番号は並び順のためのもので、表示されません。同梱の操作は 10・20・30・40 なので、間に入れたいときは 15_ のように付けます)
  2. そのフォルダに、動かしたいものを 1 つだけ入れます
    • Windows: ショートカット(.lnk)、.bat .cmd .ps1 .exe
    • Mac: .app、.sh .command
    • Linux: .sh .desktop、実行権限の付いたファイル

次にスマホで一覧を開いたときから使えます。常駐アプリの再起動は要りません。

kido.toml(なくても動きます)

フォルダに kido.toml を置くと、名前やアイコンを変えられます。

name = "マイクラ起動"          # スマホに出る名前(32 文字まで)
icon = "gamepad-2"            # アイコンの名前
confirm = "本当に起動しますか?"  # 押したときに確認を出す(200 文字まで)
run = "start.bat"             # 動かすファイルが 2 つ以上あるときに、どれかを選ぶ
  • icon は lucide.dev/icons にある名前を、英小文字のまま書きます
  • confirm = "" にすると、文章なしで「実行しますか」だけを聞きます
  • run には同じフォルダの中のファイル名だけを書けます

困ったとき

操作フォルダがおかしい・スマホに出ない

kido-agent check

フォルダごとに ✓(使える)・✗(押せない。理由と直し方も出ます)・!(動くが気を付けること)を表示します。組めているかも分かります。

本体と組み直したい・組めなかった

kido-agent pair

組み直すと、それまでの組み合わせは使えなくなります。組めないときは、ファイアウォールの許可、本体の電源、PC と本体が同じネットワークにいるかを確かめてください。

取り除く

Windows は「設定」→「アプリ」→「インストールされているアプリ」の「起動丸エージェント」からアンインストールできます。どの OS でも次のコマンドで取り除けます。

kido-agent uninstall

操作フォルダ(Kido)は残ります。要らなければ手で消してください。
